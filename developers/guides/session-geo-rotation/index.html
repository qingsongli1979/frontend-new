03
STICKY SESSION

SESSION 是一段有期限的粘性路由

SESSION适合分页、短流程和多步骤请求尽量保持同一住宅出口。它不是永久IP，也不是客户端Cookie；路由由完整代理认证用户名控制。

美国 · 15 分钟 Sticky SESSION proxy-user-sess_a8F3kP9xQ2mL_15+us
proxy-user基础代理用户 -sess_a8F3kP9xQ2mL_1512位ID与分钟数 +us小写国家码，始终在末尾
复用同一出口

连续请求使用完全相同的完整代理用户名，并尽量复用同一业务流程。

主动更换出口

使用新的SESSION ID，或切回产品支持的按请求轮转模式。

到期与异常

SESSION到期、出口不可用或调度变化时会重新分配，代码必须能恢复。

04
CONNECTION LIFECYCLE

连接池会影响你观察到的换 IP 行为

同一SESSION复用连接有助于多步骤流程减少握手，但不能突破SESSION到期或出口故障。
切换路由时关闭旧连接修改地区、SESSION或端口配置后，不要继续复用旧HTTP隧道。
浏览器按Context隔离身份不同账号或SESSION使用独立BrowserContext和Cookie存储。
记录完整路由参数日志可记录SESSION ID与地区，但不要记录代理密码。

FAQ

常见问题

SESSION 是否代表出口 IP 永远不变？

不是。SESSION 表示在设定时间窗口内尽量复用同一条粘性路由。到期、出口不可用或网络调度变化时仍可能重新分配，业务代码必须能处理出口变化。 查看隧道住宅 SESSION 格式

购买套餐时需要选择国家吗？

不需要。地区均在提取或分配代理时决定。隧道代理可选粗粒度地区，隧道住宅可选国家或地区，不限量动态住宅按套餐统一设置，两类静态代理在分配固定 IP 时按库存选择。 比较代理套餐

不限量动态住宅能否通过 SESSION 固定出口？

不能。它不使用 SESSION，而是每个套餐端口在配置的 3-30 分钟周期内固定出口并自动轮转；同一套餐的地区配置对全部端口生效。
